# 10장 - 12장 :: 얕은 복사와 깊은 복사

# 개념

## 얕은 복사(Shallow Copy) 란?

> 객체의 “최상위” 값만 복사하는 방식

원시 타입의 ‘값’은 복사(새로운 변수에 복사)  
참조 타입은 ‘참조’만 복사 (참조 주소 복사. 같은 메모리 주소를 공유)  
최상위 속성은 얕은 복사 적용되어 ⇒ 원본과 독립적으로 동작  
중첩 객체 ⇒ 참조 공유

## 깊은 복사란(Deep Copy) 란?

> 모두 새로운 메모리 공간에 복사하여 “독립적인” 복사본을 만드는 방식

타입 상관없이 ‘새로운’ 복사본 생성  
한 쪽을 복사해도 다른 쪽에 전혀 영향을 주지 않는다

# 차이점

```javascript
const obj1 = {
  category: 'bag',
  price: 2000,
  info: {
    color: 'red',
    stock: 5,
    objArr: [30,60]
  },
  arr: [1,2,3]
};

// 복사 진행
const obj2 = {...obj1} // 얕은 복사
// const obj2 = JSON.parse(JSON.stringify(obj1)) // 깊은 복사

obj1 === obj2 // false

obj2.price = 1000
obj2.info.stock = 2
obj2.arr.push(4)
obj2.info.objArr = [300, 600]
```

# 복사하는 법

### 얕은 복사

```javascript
// Object.assign()
let newObj = Object.assign({}, originalObj);

// 스프레드 연산자(...)
let newArray = [...originalArray];
let newObj = { ...originalObj };
```

### 깊은 복사

```javascript
// JSON method 사용
// 객체를 JSON 문자열로 변환 -> 다시 객체로 변환 (함수, undefined, Symbol, Date 등은 JSON으로 변환 불가)
const obj2 = JSON.parse(JSON.stringify(obj1));

// lodash 사용
import _ from "lodash";
const obj2 = _.cloneDeep(obj1);

// structuredClone
// 위 문제들을 해결하고자 2021년 7월에 나온 자바스크립트 API (native method)
// 구조화된 복제 알고리즘 실행
// Node 17 이상 가능
// JSON 방식의 단점 보완(ex. Date 객체 등 안전하게 복사 가능). but 함수, DOM 노드 복사 불가
const obj2 = structuredClone(obj1);
```

[//]: # ([structuredClone&#40;&#41; global function - Web APIs | MDN]&#40;https://developer.mozilla.org/en-US/docs/Web/API/structuredClone&#41;)

## 주의점

> 💡**얕은 복사**에서 동일한 참조 타입이더라도, 위치 레벨에 따라 다르게 동작한다 !

```javascript
const obj1 = {
  category: 'bag',
  price: 2000,
  info: {
    color: 'red',
    stock: 5,
    objArr: [30,60]
  },
  arr: [1,2,3]
};

const obj2 = Object.assign({}, obj1);  // 얕은 복사
obj2.arr.push(4); // 1 
obj2.arr = [4, 5, 6]; // 2
obj2.info.objArr = [300, 600];
```

### 1. `arr`

객체의 최상위 속성

`push` : 같은 메모리 주소를 공유하기 때문에 양쪽 다 `4` 추가  
`=` : 재할당을 하게 되면서, `obj2` 는 새로운 배열을 가리키게 되어, 원본과 독립적으로 동작

### 2. `objArr`

중첩된 객체 속성에 있는 배열  
**참조**만 복사  
[`obj1.info`](http://obj1.info) , [`obj2.info`](http://obj2.info) 는 서로 같은 객체를 참조 ⇒ 하나라도 재할당 등 값을 바꾸면 두 객체 모두 영향

⇒ 얕은 복사는 ‘**최상위 레벨**’에서만 작동하고, 중첩된 객체는 ‘**참조를 공유**’ 한다
