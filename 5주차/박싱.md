> 원시 타입은 해당 타입의 객체의 프로토타입 메서드에 접근이 가능하다  
> ⇒ AutoBoxing

# 박싱

원시 타입을 객체 타입으로 변환하는 과정

### 오토 박싱 (=자동 박싱) Autoboxing

자바스크립트는 원시 값에 대해 자동 박싱을 지원한다

```jsx
let str = "hello";
console.log(str.length); // 5

let num = 123.456;
console.log(num.toFixed(2)); // "123.46"
```

문자열 리터럴로 생성한 `str` 은  
자바스크립트 엔진이 내부적으로 `String` 객체로 변환시켜 프로토타입 메서드를 사용할 수 있게 한다.

값 자체는 원시 타입이지만,  
method 호출시 자동으로 String 객체 타입으로 변환하고 다시 되돌린다.  
→ `new String('hello')` 로 변환  
이를 자동 박싱 (Autoboxing) 이라고 한다.

‘일시적’인 래퍼 객체(wrapper object)가 생성되며,  
이후에 메모리에서 해제되는 것이다.

### 수동 박싱

new 생성자를 통해 직접 박싱할 수 있다.

```jsx
var a = new Boolean(true);
var b = new String('javascript');

console.log(typeof a) // object(o) boolean(x)
console.log(a) // true(x) Boolean{} 객체(o)

// 'javascript'(x) 자바스크립트 객체(o)
console.log(b) // // String {0: "j", 1: "a", 2: "v", 3: "a", 4: "s", 5: "c", 6: "r", 7: "i", 8: "p", 9: "t", length: 10} 객체가 나온다
```

# 언박싱

`valueOf` method를 통해, 박싱된 객체의 데이터를 꺼낼 수 있다.

```jsx
let a = new String("hello");

a; // String {"hello"}
a.valueOf(); // "hello"
```
