# 16장 - 18장:: 일급 객체

> 📅 스터디 날짜: 2024년 10월 14일

### 일급 객체란?

first-class object  
다른 객체들에 일반적으로 적용 가능한 연산을 모두 지원하는 객체

1. 무명의 리터럴로 생성
2. 변수나 자료구조(객체, 배열..)에 저장 가능
3. 함수의 매개변수에 전달 가능
4. 함수의 반환값으로 사용 가능

### 자바스크립트에서 일급 객체는 어떤 의미?

![img.png](images/img.png)

고차 함수나 콜백 패턴과 같은 `함수형 프로그래밍` 에 적용 가능  
자바스크립트는 함수형 프로그래밍 언어다.

# 함수형 프로그래밍

> 💡 자료 처리를 [수학적 함수](https://ko.wikipedia.org/wiki/%ED%95%A8%EC%88%98)의 계산으로 취급하고  
상태와 가변 데이터를 멀리하는 [프로그래밍 패러다임](https://ko.wikipedia.org/wiki/%ED%94%84%EB%A1%9C%EA%B7%B8%EB%9E%98%EB%B0%8D_%ED%8C%A8%EB%9F%AC%EB%8B%A4%EC%9E%84)의 하나이다.

### 프로그래밍 패러다임이란?

프로그래머에게 프로그래밍의 관점을 갖게 하고,  
코드를 어떻게 작성할 지에 대해 결정한다.

### 수학적 함수의 계산

```jsx
y = 3 + 5
```

단순 숫자의 계산처럼,  
외부 상태나 데이터에 의존하지 않고 동일한 인풋에는 동일한 아웃풋이 나오게 한다

### **상태와 가변 데이터의 배제**

함수형 프로그래밍에서는 상태 변경과 가변 데이터를 피하려고 한다.  
⇒ 데이터는 불변하며 상태는 변경되지 않도록 설계

> 함수형 프로그래밍은 함수의 응용을 강조

### 함수 합성 (Composition)

함수형 프로그래밍에서는 함수 조합을 자주 사용한다.  
작은 단위의 순수 함수를 결합해 복잡한 연산을 수행할 수 있다  
⇒ 코드 재사용성을 높이고, 함수 조합을 통해 복잡한 로직을 쉽게 구현할 수 있게 한다.

### **순수 함수 사용 (Pure function)**

순수 함수는 동일한 입력에 대해 항상 동일한 결과를 반환한다.  
각각의 함수는 독립적으로 동작하기에, 코드의 동작 결과가 예측이 가능해지며 사이드 이펙트를 방지할 수 있다  
⇒  코드의 예측 가능성과 안정성을 높여준다

### 불변성 (Immutable)

함수형 프로그래밍에서는 데이터가 변할 수 없다.  
기존 데이터를 바꾸는 것이 아니라, 기존 데이터의 복사본을 해 데이터를 변경한다.

### 고차 함수 (higher-order function)

= 함수를 다루는 함수  
함수를 인자로 전달하거나 반환하는 등의 동작이 가능하다. 즉, 다른 함수를 조작할 수 있는 함수이다.  
함수형 프로그래밍 언어에서는, 함수도 값으로 취급되기 때문이다.

자바스크립트의 내장 method 중에서 map, filter, reduce 등이 있다.

```jsx
const numbers = [1, 2, 3, 4, 5];

const arr = numbers.map(num => num * 2);
console.log(arr); // [2, 4, 6, 8, 10]
```

map 함수는 `num => num * 2` 함수를 인자로 받았다.
